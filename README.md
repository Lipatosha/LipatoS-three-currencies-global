# LipatoS - Три валюты D&D5e

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который полностью убирает электрум (**EP**) и платину (**PP**) из экономики игры.

Остаются только три валюты:

- **CP** — медь;
- **SP** — серебро;
- **GP** — золото.

## Версия

**3.0.1**

## Что делает модуль

- полностью скрывает **EP** и **PP** в интерфейсе D&D 5e;
- удаляет EP и PP из глобальной конфигурации валют D&D 5e;
- существующий электрум один раз переводит в серебро: **1 EP = 5 SP**;
- существующую платину один раз переводит в золото: **1 PP = 10 GP**;
- после конвертации принудительно удерживает EP и PP на значении **0**;
- очищает EP и PP у мировых персонажей и несвязанных токенов на сценах;
- удаляет EP и PP из глобальных валют **Item Piles**;
- удаляет EP и PP из индивидуальных настроек торговцев и куч предметов Item Piles.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-three-currencies-global/main/module.json`
