# История изменений

## 4.2.3

- «Количество», «Вес», «Цена» и «Заряды / Использования» получили одинаковую ширину 76 px в заголовках и строках.
- Убраны старые внешние отступы, которые давали неравномерный визуальный шаг между колонками.
- Заголовок «Заряды» больше не привязывается к первой цифре значения `1/1`; он центрируется по всей колонке.
- Значение `1/1` центрируется как единая группа, а пустой прочерк — строго по центру той же ячейки.
- Сохранено отображение веса в формате «число → иконка».

## 4.2.2

- Добавлены одинаковые горизонтальные отступы между служебными колонками инвентаря.
- Исправлена обработка веса во всех строках секции: иконка веса теперь всегда идёт после числового значения.
- Для веса установлен стабильный визуальный зазор между числом и иконкой.
- Содержимое колонок «Заряды / Использования» центрируется в своей ячейке, включая прочерк «—».
- Сохранена безопасная схема 4.2.1: значения и кнопки D&D5e не переносятся и не позиционируются вручную.

## 4.2.1

- Полностью откатана ломающая строки схема центрирования из 4.1.8–4.2.0.
- Восстановлена штатная разметка D&D5e для количества, веса, цены, броска, формулы и зарядов.
- Больше не используются absolute/grid/flex для перемещения значений и кнопок.
- Для совпадения центров теперь смещается только заголовок колонки к реальному центру уже отображаемого числа/формулы.
- Иконка веса снова целая и располагается после числа с нормальным отступом.

## 4.2.0

- Полностью удалена предыдущая схема центрирования 4.1.8/4.1.9.
- Значение каждой строки теперь привязывается к фактическому центру заголовка соответствующей колонки, а не к центру собственной ячейки строки.
- Исправлено систематическое смещение значений влево относительно заголовков.
- Восстановлены нормальные отступы между числом/формулой и иконками.
- Иконка веса остаётся после числа; иконка цены и типа урона также располагается справа с отдельным зазором.
- При изменении размера листа координаты автоматически пересчитываются.

## 4.1.9

- Полностью заменён предыдущий flex/grid-подход к центрированию.
- Число количества, число веса, сумма цены и формула теперь жёстко позиционируются в 50% ширины соответствующей колонки.
- Заголовки тех же колонок также принудительно центрируются в их собственных ячейках.
- Кнопки «−/+» и декоративные иконки вынесены из расчёта центра.
- Иконка веса остаётся после числового значения и больше не может сдвигать его.

## 4.1.8

- Значения инвентарных колонок центрируются по самому числу/формуле, а не по общей ширине значения вместе с иконками.
- Количество центрируется по числу; кнопки «−» и «+» располагаются по сторонам и не влияют на центр числа.
- Вес центрируется по числу, а иконка веса перенесена после значения.
- Цена центрируется по сумме, иконка валюты остаётся справа и не сдвигает сумму.
- Формула урона центрируется по тексту формулы, иконка типа урона не участвует в вычислении центра.
- Числовые значения зарядов/использований центрируются как единая запись.

## 4.1.7

- Полностью удалены все собственные правила центрирования и фиксированной ширины колонок инвентаря.
- Удалён JavaScript, который измерял ячейки и сдвигал заголовки через `transform`.
- Удалены `justify-content`, `text-align`, фиксированные `width/flex` для колонок «Количество / Вес / Цена».
- Центрирование и геометрия инвентаря снова полностью контролируются базовой системой D&D5e.
- Сохранены только порядок «Количество → Вес → Цена» и пустая цена у физических предметов валюты.

## 4.1.6

- Исправлено фактическое смещение заголовков «Количество / Вес / Цена» относительно значений.
- Заголовки теперь выравниваются по реальным координатам ячеек первой строки каждой секции после рендера.
- Добавлен повторный пересчёт при изменении размера листа, поэтому центрирование сохраняется при растягивании окна и адаптивном скрытии колонок.

## 4.1.5

- Физические предметы валюты переименованы: «Золотая монета» → «Золото», «Серебряная монета» → «Серебро», «Медная монета» → «Медь».
- Существующие мастерские предметы монет автоматически получают новые имена при запуске ГМ.
- Колонки «Количество», «Вес» и «Цена» получили фиксированные одинаковые ширины для заголовков и строк предметов.
- Содержимое всех трёх колонок принудительно центрируется, включая цену, которая в базовом D&D5e была прижата вправо.

## 4.1.4

- Во всех стандартных инвентарных списках порядок колонок изменён на «Количество → Вес → Цена».
- Только для трёх физических предметов-монет колонка цены сделана полностью пустой.
- Цена физической золотой, серебряной и медной монеты нормализуется в 0, включая уже созданные стопки.
- В колонке цены обычных предметов возвращены базовые иконки валют D&D5e; пользовательские изображения остаются у денежной строки персонажа и самих предметов-монет.
- Из окна передачи монет удалены поясняющие тексты; остались количество, кнопки «Всё»/«Половина» и «Подтвердить».

## 4.1.3

- Убран двойной tooltip названия монеты: больше не используется нативный HTML `title`, остаётся только подсказка Foundry.
- В окно передачи добавлены кнопки «Всё» и «Половина»; «Половина» отмечена иконкой `fa-circle-half-stroke`.
- Кнопки «Всё» и «Половина» только меняют значение поля количества и не закрывают окно.
- Для фактической передачи требуется отдельное подтверждение кнопкой «Подтвердить».
- Перетаскивание физической стопки монет из контейнера в инвентарь персонажа теперь тоже всегда открывает окно выбора количества.
- Частичная передача из контейнера уменьшает исходную стопку, полная — удаляет её после зачисления валюты персонажу.

## 4.1.2

- Перенос валюты в контейнер переведён на глобальный обработчик drag/drop, чтобы системные обработчики D&D5e больше не перехватывали пользовательское перетаскивание.
- После броска GP/SP/CP на контейнер всегда открывается окно выбора количества, даже если доступна только одна монета.
- Добавлены единые подсказки для всех иконок валюты: «Золотая монета», «Серебряная монета», «Медная монета».
- Подсказки работают также у иконок цены предметов и у динамически появляющихся валютных элементов.
- Убрана подсказка «Перетащить ... в контейнер» с денежной строки персонажа.

## 4.1.1

- Исправлено отсутствующее изображение медной монеты: повреждённый WEBP заменён новой корректной версией из исходного PNG.
- Денежные иконки персонажа теперь рендерятся настоящими draggable-изображениями, а не фоновыми иконками.
- Добавлен явный dragover/drop для контейнеров, поэтому GP/SP/CP теперь действительно можно перетаскивать в контейнер.
- Контейнер подсвечивается при наведении переносимой валюты.

## 4.1.0

- Иконки GP, SP и CP в денежной строке персонажа заменены на пользовательские изображения монет из модуля.
- Иконки GP/SP/CP стали перетаскиваемыми мышью.
- Валюту из счётчика персонажа можно бросить на контейнер в инвентаре или в открытый лист контейнера.
- При переносе появляется выбор количества; счётчик персонажа уменьшается, а в контейнере создаётся физическая стопка соответствующих монет.
- Перетаскивание валюты из счётчика в обычную область инвентаря блокируется: физические монеты создаются только через контейнер.
- Сохранена возможность разделять физические стопки внутри контейнеров без обратного склеивания.

## 4.0.1

- Исправлена команда «Разделить» для физических монет внутри контейнеров.
- Разделённые стопки больше не объединяются обратно сразу после создания.
- Автоматическое зачисление монет в GP/SP/CP при переносе в обычный инвентарь персонажа сохранено.

## 4.0.0

- Убрана стандартная строка валюты только из листов предметов-контейнеров; денежная строка персонажей не затрагивается.
- Добавлены предметы «Золотая монета», «Серебряная монета» и «Медная монета» с пользовательскими иконками.
- При первом запуске ГМ создаётся папка «LipatoS — Монеты» с тремя мастерскими предметами.
- Монеты можно хранить в контейнерах как физические стопки.
- Перетаскивание стопки монет в обычный инвентарь персонажа автоматически добавляет её количество в GP/SP/CP и удаляет предмет.
- Перетаскивание на контейнер сохраняет монеты физическими предметами.
- Одинаковые монеты в одном контейнере автоматически объединяются в стопку.
- Существующая валюта старых контейнеров автоматически и без потери переносится в физические предметы-монеты.
- EP и PP в контейнерах при миграции переводятся в SP и GP по прежним курсам.
- Релиз переведён на автоматическую сборку GitHub Actions.

## 3.0.1

- Добавлена совместимость с D&D5e 6.0.5.
- Обновлены манифест и установочный архив модуля.
- Рабочая логика модуля сохранена без изменений.

## 3.0.0

- Текущая рабочая версия перенесена в линейку модулей LipatoS.
- Внутренний ID изменён на `lipatos-three-currencies-global`.
- Полностью отключены электрум (EP) и платина (PP).
- Существующий EP конвертируется в SP по курсу **1 EP = 5 SP**.
- Существующий PP конвертируется в GP по курсу **1 PP = 10 GP**.
- EP и PP принудительно удерживаются на нуле после конвертации.
- Добавлена очистка валют у мировых актёров и несвязанных токенов.
- EP и PP удаляются из глобальных и индивидуальных настроек Item Piles.
